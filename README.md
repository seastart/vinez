# Vinez

**一套 AI 工程能力，整个团队随时调用。** · *A team's AI engineering capability, on call.*

---

## 中文

Vinez 是装在团队一台常开机器上的服务端（`vinezd`）：成员从聊天、网页或终端发一句工程需求，它在正确的项目环境里持续执行到交付，需要人时主动来问。

**安装：**

```bash
curl -fsSL https://vinez.ai/install.sh | sh
```

服务端支持 macOS 与 Linux（Apple Silicon / Intel / x86_64 / arm64）；桌面与移动客户端见[下载页](https://vinez.ai/download)。

## English

Vinez runs as a daemon (`vinezd`) on one always-on machine your team owns. A teammate sends an engineering request from chat, the web, or a terminal; Vinez carries it out to delivery in the right project environment, and comes back to ask when it needs a human.

**Install:**

```bash
curl -fsSL https://vinez.ai/install.sh | sh
```

The server runs on macOS and Linux (Apple Silicon / Intel / x86_64 / arm64); desktop and mobile clients are on the [download page](https://vinez.ai/download).
